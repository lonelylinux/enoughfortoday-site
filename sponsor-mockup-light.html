Why this direction

  • One continuous metaphor across all four tiers — each name is a real light source, growing from a spark you can barely see to a beacon meant to be seen from far away. Nothing is arbitrary or needs a decoder.
  • Warmth and guidance instead of power and electricity — closer to the app's own tone (rest, recovery, pacing) than a circuit-board idea ever was.
  • "Spark" survives from the first round, so nothing you already liked gets thrown away.
  • Same pricing, same card layout, same no-"Recommended"-tag, purpose-first copy as the first mockup — only the names, icons, and colors changed, so this is a fair apples-to-apples comparison.
